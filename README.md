# LOOP

Website for LOOP, vintage · workshops · secondhand, Brunnengasse 2, Füssen.

Static HTML, no framework, no build step in this repo. The pages are generated by `tools/site_build.py`
in the project folder (dates, prices and texts live at the top of that script), pictures by `tools/site_renders.py`.
Design sources, fonts and brand files live in the project folder, not here.

- `index.html` home · `workshops.html` the four launch workshops · `impressum.html`, `datenschutz.html` stubs until launch
- Font: Jost via Bunny Fonts (EU, no tracking). No cookies, no analytics, no forms.
- Status: preview. Every page carries `noindex` until `LIVE = True` in the build script.
